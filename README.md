# Responsibility Interoperability Records

Published bounded interoperability test records for Responsibility Infrastructure®.

This repository is a curated public record surface. It contains five completed bounded external-system test records and a separately identified, publication-authorised independent-receiver research record. Detailed research, unpublished targets, internal methodology, source repositories, development material and third-party Git implementation detail are not published here.

## Publication boundary

Every public interoperability record follows the same bounded publication pattern: identify the tested third-party system, publish the test class and bounded result, state the research context and claims boundary, and publish no third-party Git implementation detail.

For external-system interoperability test summaries, do not publish third-party repository URLs, GitHub organisation or user handles, branches, commit hashes, file paths, package names, source-code excerpts, repository structure or other implementation-level Git detail. The authorised independent-receiver reports are retained verbatim as separate authored research works, including their original internal file references; those references do not authorise public release of referenced code, fixtures or result files. Those materials may be examined internally for research and testing, but they are not part of the public interoperability record.

## Separate independent-receiver research (not counted among the five external-system tests)

- [RI-W3C-HIRE-EIGHT-001 — Eight-case hiring-agent authority and escalation](./RI-W3C-HIRE-EIGHT-001.md)

This separate, consented synthetic reproducibility exercise documents Prasanna Bableshwar's non-blind independent receiver run and ten specification gaps. His **authored findings and run report are reproduced verbatim** with his written personal-capacity and non-endorsement conditions. The actual receiver code, fixtures and result files have **not** been authorised for public release and are not published in this repository. The reports reference their own internal file names as part of the original approved text, not to disclose the underlying implementation.

This record does **not** increase the five published external-system test count, establish correctness of the eight expected outcomes, demonstrate blind interoperability, or establish W3C endorsement or RI conformance. Attribution and author rights are preserved; no open-source licence is implied for independently authored reports.
